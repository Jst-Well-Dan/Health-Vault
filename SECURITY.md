# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a vulnerability involving authentication, exposed health data, credentials, backups, report attachments, or Tailscale access.

Use the repository's private security-advisory reporting feature. If it is unavailable, contact the maintainer through the contact method listed on the repository profile and include:

- affected version or commit;
- reproduction steps that use only synthetic data;
- expected and actual behavior;
- potential impact.

Do not attach real health records, passwords, API keys, session cookies, database files, or logs containing them.

## Scope

Supported releases are the latest published release and the current `main` branch. This project is designed for a single trusted household and is not intended for public Internet exposure.
